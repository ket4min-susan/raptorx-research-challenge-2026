# Technical Research Report: Wrapped SOL (SOL)

## 1. What It Is

**Wrapped SOL (SOL)** is the native SPL token standard representation of Solana's native asset, SOL, deployed on the Solana blockchain. The contract address is `So11111111111111111111111111111111111111112`, which serves as the canonical wrapped version of SOL used throughout the Solana DeFi ecosystem.

Wrapped SOL is categorized by CoinGecko under **"Crypto-Backed Tokens," "Wrapped-Tokens,"** and **"Solana Ecosystem,"** reflecting its role as a bridge between Solana's native token and the broader SPL token ecosystem. This wrapping mechanism enables SOL to be utilized in DeFi protocols, DEXs, lending platforms, and NFT marketplaces that require SPL-compliant token standards.

The token maintains a **1:1 peg with native SOL**, with the CoinGecko data showing a conversion rate of approximately 0.99955633 SOL per wrapped SOL, confirming near-perfect parity. The project's official website is [solana.com](https://solana.com), with the primary social media presence on X (formerly Twitter) at [@solana](https://x.com/solana).

Key characteristics include:
- **Token Type:** SPL token on Solana blockchain
- **Decimal Places:** 9 (matching native SOL)
- **Total Supply:** 12,428,850.51 WSOL
- **Circulating Supply:** 12,495,224.48 WSOL
- **Max Supply:** Infinite (uncapped, matching native SOL's inflationary model)
- **Primary Trading Pair:** SOL/USDC on Orca DEX

The primary trading pair analyzed in this report is the **SOL/USDC** pair on the Orca DEX, with the pair contract address `Czfq3xZZDmsdGdUyrNLtRhGc47cXcZtLG4crryfu44zE`. This pair was created on June 30, 2023, and represents one of the most liquid trading venues for SOL on the Solana ecosystem.
